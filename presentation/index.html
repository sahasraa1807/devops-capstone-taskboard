Infrastructure, Kubernetes & Monitoring

Terraform AWS EKS, Helm Packaging & Observability

☁️ Terraform AWS (IaC)

  • Region: ap-south-1 (Mumbai).
  • VPC: 10.0.0.0/16 with 2 Public & 2 Private subnets across 2 AZs.
  • Gateways: Internet Gateway + NAT Gateway for secure egress.
  • AWS EKS 1.30: Managed control plane + EC2 Worker Node Group (t3.medium).

📦 Kubernetes & Helm

  • Helm Chart: helm/taskboard/ modular templates.
  • High Availability: 2 replicas each for frontend & backend.
  • Nginx Ingress: Unified routing (/ to frontend, /api to backend).
  • Storage: PostgreSQL with 2Gi PVC.
  • HPA: Autoscaling 2 → 5 pods when CPU exceeds 70%.

📊 Observability & Labs

  • Prometheus: Scrapes /metrics via ServiceMonitor every 15s.
  • Grafana: Live dashboard tracking HTTP rate, p95 latency, and CPU load.
  • Troubleshooting Labs: Simulation of ImagePullBackOff and Service selector mismatch.
